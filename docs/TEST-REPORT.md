# Проверка BLOCK 17 · 0.1.0

Дата: 22 октября 2026. Репозиторий: `elcin31/BLOCK-17`.

Это играбельная первая версия. Ниже приведены выполненные проверки и границы результата; наличие кода не считается доказательством прохождения проверки.

## Среда

- Godot 4.6.3 Standard, GDScript, Compatibility renderer.
- Linux x86_64; отрисовка через Xvfb и Mesa llvmpipe, без аппаратного GPU.
- Java 21; Android SDK 36; Build Tools 36.0.0.
- APK: `org.block17.livingcity`, версия `0.1.0`, minSdk 24, targetSdk 36.
- Архитектуры: ARM64, ARMv7, x86_64. Подпись ключом разработки.

## Автоматические проверки

`tests/test_simulation.gd`: **1108 проверок, 0 провалов**.

- Создание 120 жителей, начальное жильё и работа, корректные семейные ссылки.
- Передвижение на работу и в школу по дорожной сети.
- Строительство офиса создаёт 22 вакансии и списывает стоимость из казны.
- Новое жильё снижает множитель аренды.
- Занятый участок, нехватка средств, выход за карту и пересечение дороги отклоняются без ошибочного строительства.
- Новая дорога добавляется в граф навигации.
- Покупки, аренда, налоговые поступления и суточный бюджет действительно меняют данные модели.
- Открытие бизнеса из личных накоплений; потеря работы при пустой кассе.
- Положительные встречи образуют взаимные пары; отрицательные — конфликты.
- Переезд домохозяйства сохраняет семью и не превышает вместимость жилья.
- Реальный JSON-файл сохраняется и загружается; сохраняются деньги, время, все жители и точное состояние RNG.
- После загрузки ещё сутки симуляции дают те же деньги и маршруты, что непрерывная игра.
- Повреждение основного файла восстанавливается из резервной копии; некорректная ссылка жителя отклоняется.
- Прогон 20 игровых дней: население сохранено, потребности ограничены, суммы конечны, кошельки неотрицательны, маршруты проходят по дорогам, журналы не растут бесконечно, итоговый город проходит проверку сохранения.

Первый прогон 20 дней до расширения тестов занял 11,2 с. Повторный прогон расширенного набора при одновременно работающем программном Android-эмуляторе — 27,3 с. Это замеры вычисления модели на сервере, **не FPS телефона**.

Импорт и выполнение GDScript проходят без ошибок скриптов. Подпись первого APK проверена `apksigner`: схемы v2 и v3 действительны. Манифест проверен `aapt`; сетевые разрешения не запрошены. Итоговая сборка и GitHub Actions проверяются перед публикацией релиза.

## Границы версии

Население фиксировано на 120 жителях; старение, рождения, смерти и приток новых жителей не реализованы. Цены и базовые зарплаты фиксированы; внешние заказы упрощены. Нет товарных складов, производственных цепочек, сноса и интерьеров. Машины служат декорацией. Это не проверенный релиз для Google Play: APK имеет подпись разработки.

На физическом Xiaomi Redmi Note 12 тестирования и измерения FPS/потребления батареи не проводилось. Использованы совместимый OpenGL ES 3 renderer, ограниченные журналы, кэшируемые статические слои и интерполяция движения. Считать целевые 30/60 FPS на устройстве подтверждёнными пока нельзя.
